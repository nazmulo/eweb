# 🛍️ ShopNova — E-commerce Website

ShopNova is a modern and responsive e-commerce website built using **HTML, CSS, and Vanilla JavaScript**. It provides a simple shopping experience with product browsing, category filtering, search, and a functional shopping cart.

## 🌐 Live Website

**Live Demo:** https://nazmulo.github.io/eweb/

---

## ✨ Features

* 🛍️ Modern e-commerce user interface
* 📱 Fully responsive design
* 🔎 Product search functionality
* 🏷️ Product category filtering
* 🛒 Add products to shopping cart
* ➕ Increase product quantity
* ➖ Decrease product quantity
* ❌ Remove products from cart
* 💰 Automatic cart subtotal calculation
* 💾 Cart data stored using `localStorage`
* 🎨 Clean and modern UI
* ⚡ Built with Vanilla JavaScript
* 📦 Dynamic product rendering

## 🛒 Shopping Cart

The shopping cart is powered by JavaScript.

Users can:

* Add products
* Increase quantity
* Decrease quantity
* Remove products
* View total price

The cart is saved in the browser using:

```javascript
localStorage
```

This means the cart remains available after refreshing the page.

---

## 🔍 Search & Filtering

ShopNova includes two ways to find products.

### Search

Users can search products by name.

Example:

```text
Wireless Headphones
```

### Category Filter

Products can be filtered by:

* All
* Fashion
* Electronics
* Shoes
* Accessories
